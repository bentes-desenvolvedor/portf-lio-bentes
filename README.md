# Portfólio — Nicolas Bentes

Site pessoal para apresentar projetos, tecnologias e formas de contato. A página usa HTML, CSS e JavaScript sem frameworks, com layout responsivo, painel de resumo e filtros para navegar pelos projetos.

## Projetos

- **Hydration App** — plataforma de hidratação com mascote virtual e acompanhamento de metas.
- **BentesNews** — portal de notícias. [Acessar site](https://bentes-desenvolvedor.github.io/BentesNews/).
- **Bentes.SGE** — sistema de gestão escolar e ambiente de aprendizagem. [Acessar site](https://bentes-desenvolvedor.github.io/Bentes.SGE/).
- **Snake Singleplayer** — versão individual do clássico jogo da cobrinha. [Acessar jogo](https://bentes-desenvolvedor.github.io/snake-singleplayer/).

Os cards levam diretamente aos sites ou repositórios de cada projeto.

## Tecnologias

- HTML5 e CSS3
- JavaScript (Vanilla)
- Font Awesome
- Google Fonts (DM Sans e Playfair Display)

## Como visualizar

Abra `index.html` em um navegador. Para publicar na web, hospede os arquivos deste repositório em um serviço estático, como o GitHub Pages.
